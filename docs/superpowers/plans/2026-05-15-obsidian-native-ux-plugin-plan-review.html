계획 리뷰 / Phase 3 Obsidian-native UX Plugin

구현 계획은 확정된 spec을 실행 가능한 TDD 단위로 분해한다

이 리뷰는 2026-05-15-obsidian-native-ux-plugin-plan.md가 확정된 spec 결정, 공식 Obsidian 문서 제약, 테스트와 배포 준비 기준, subagent가 나눠 작업할 수 있는 파일 소유 범위를 충분히 반영했는지 확인한다.

판정 사용자 리뷰 가능. 사용자가 이 계획을 accept하기 전까지 구현은 시작하지 않는다.
실행 방식 subagent-driven development를 추천한다. 각 작업은 TDD red-green 체크포인트와 최종 리뷰 gate를 통과해야 한다.
리스크 기준 copy-installed smoke, 명시적 raw promotion, 안전한 ribbon 진입점이라는 핵심 안전장치를 유지한다.

리뷰 결과

계획 품질 점검

blocker 없음: TDD 구조

주요 동작은 구현 전에 failing test 또는 smoke check로 시작한다. 최종 검증 번들도 명시되어 있다.

blocker 없음: 파일 소유 범위

core port, core use-case, CLI regression, plugin package, smoke script, 문서를 서로 다른 write scope로 나눈다.

blocker 없음: 공식 문서 정합성

계획은 Obsidian sample plugin의 package 형태와 Vault.process() 중심의 Vault API 가이드를 따른다.

구현 주의: port migration

현재 core 함수 일부는 filesystem 기반이다. 작업자는 추출을 점진적으로 진행하고 각 task 뒤 CLI 동작을 보존해야 한다.

구현 주의: raw card parsing

초기 raw promotion은 보수적인 active-card 감지가 필요할 수 있다. 자동 promotion은 계속 금지된다.

구현 주의: Obsidian CLI 사용 가능성

로컬 Obsidian runtime이 있을 때 GUI E2E를 실행한다. 실행할 수 없으면 defer할 정확한 명령과 미검증 상태를 명시해야 한다.

검증 Gate

완료 주장 전에 필요한 검증
Core rtk pnpm --filter @kanban-task-engine/core test
CLI rtk pnpm --filter @kanban-task-engine/cli test
Plugin rtk pnpm --filter @kanban-task-engine/obsidian-plugin test and build
Smoke plugin artifact를 disposable vault에 copy-install한다. symlink install은 acceptance evidence로 인정하지 않는다.
Final bundle rtk pnpm -r build, rtk pnpm -r test, rtk pnpm test:docs, rtk pnpm eval:hardening, rtk git diff --check
